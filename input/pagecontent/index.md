### Introduction
This Implementation Guide is a personal testing area for exploring FHIR profile behaviour and FHIR tooling. It is not intended to for genuine usage. It may include test profiles and examples based on profiles defined in HL7 Australia FHIR Implementation Guides.

Test artefacts in this guide are created for testing purposes only. They are not intended for implementation use and do not define additional requirements for the source Implementation Guides.
